# git-branch-switch

## How to use it

1. Add alias to your .bashrc file:

```shell
alias gitbs='node ~/github/git-branch-switch/main.js'
```

2. Run command 'gitbs' in a directory of git repository
```
> gitbs
```
then it will show all the local branches.

4. Select branch with ↓/J, ↑/K, and 'Enter' to checkout the branch.
6. Othen commands:
   - Delete branch: Ctrl+K
   - Exit Program:  Q/Esc/Ctrl+C
